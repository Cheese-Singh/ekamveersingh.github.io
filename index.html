Gwen
Flagship · v1.1 v1.1 · Live

Gwen is a local-first, agentic voice AI assistant for Apple Silicon. The system combines a native SwiftUI interface with a Python/FastAPI backend, MLX-powered on-device inference, voice interaction, tiered model routing, tool-calling, persistent memory, multimodal I/O, and macOS system control. The project evolved from the MLX exploration series into a consolidated personal-assistant architecture spanning lightweight on-device models and higher-capability cloud models. Gwen incorporates persistent user state, session history, semantic memory and retrieval, real-time voice interaction, sentence-level TTS, acoustic echo cancellation, voice/text mode switching, interruption handling, and support for image, PDF, and Word document generation and reading.

Gwen v1.1 is now live.

LLM Cascade Eval
Research Pilot

A weak-to-strong Ollama model cascade for code generation, benchmarked against Gemini 3.6 Flash. Code problems are verifier-gated: each candidate is executed against the problem's test suite, and escalation happens only on a verified failure — not on LLM review. Open-ended problems use a separate AGREE/EDIT/REWRITE review protocol, since no deterministic check exists there.

In a 3-problem pilot, the cascade reached 3/3 correctness, matching both governed Gemini retry conditions and beating ungoverned one-shot Gemini (2/3). Switching code evaluation from review-gating to verifier-gating cut cascade token cost by 61.5% on the same problems (23,645 → 9,101 tokens) — though the cascade still costs more than one-shot Gemini.
